# 兜风俱乐部 · 鹈鹕的海岸骑行

一只戴着黄色骑行帽、系着绿色围巾的鹈鹕，骑着珊瑚色自行车沿海岸兜风。

整个页面以 SVG、CSS 和原生 JavaScript 编写，包含插画与 2D 循环动画，无需安装依赖或构建，可离线运行。

## 打开动画

下载仓库后，用浏览器打开 **[index.html](index.html)** 即可播放。

也可以在仓库目录启动本地预览：

```sh
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 动画与交互

- 双脚跟随踏板交替运动，车轮与路面同步滚动。
- 围巾飘动、眨眼、花束轻摆，以及云朵、海浪和路边植物的移动。
- 悠闲、轻快、追风三档骑行速度。
- 暂停与继续播放。
- 点击铃铛播放合成车铃，并显示「叮铃～」。声音仅在主动操作后播放。
- 适配桌面和手机屏幕；系统启用减少动态效果时默认暂停。

| 快捷键 | 操作 |
| --- | --- |
| 空格 | 暂停或继续；焦点在按钮上时执行该按钮的操作 |
| ← / → | 降低或提高骑行速度 |
| B | 按响车铃 |

## 文件

`index.html` 包含全部 SVG 插画、样式和动画逻辑，不依赖外部图片、字体或 JavaScript 库。
